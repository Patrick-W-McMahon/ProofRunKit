# README language logos

These SVG badges are shown in the root [README](../../../README.md) to indicate language compatibility. They are not hotlinked; this directory is the source used on GitHub.

Marks are used unmodified (the same path data as the upstream icon) and only to indicate that ProofRunKit can, or is planned to, work with that language. They are trademarks of their respective owners. This project is not affiliated with or endorsed by those owners. Do not recolor, crop, or restyle the brand marks; the rounded white tile around each icon is a neutral frame for contrast in GitHub light and dark themes, not part of the mark.
